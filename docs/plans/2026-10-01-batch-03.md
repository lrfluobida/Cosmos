# Batch 03 implementation plan

> Use superpowers:subagent-driven-development. Dedicated implementer and independent reviewer per task; one `batch03_merger` integrates approved commits.

## Goal

Connect role execution, explicit requirement confirmation and artifact integration so a later end-to-end task can generate a game through Cosmos itself.

## Architecture

Use the reviewed pi adapter and persisted controller. Roles receive frozen task context and scoped tools, and submit candidate artifacts. A separate reviewer context reads the same requirement version and the exact candidate. Host checks, rather than model claims, authorize integration and completion.
