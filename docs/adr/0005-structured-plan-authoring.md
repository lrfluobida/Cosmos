# 验收计划采用结构化作者输入

决策已接受；接受时 SOURCE 实施中，代码完成状态由[任务卡](../specs/cos147-structured-plan-authoring.md)另行记录。

设计作者负责游戏步骤、观测和checkpoint，宿主负责验收计划的固定外层、确认来源与JSON序列化。真实验证中，裸文本追加先后产生未闭合JSON和错层reopen；因此为新任务提供固定文件的save/append接口，保留raw编辑用于局部纠正，而不扩展为通用JSON编辑器。

保存得到的仍是执行验收计划草稿，原结构/覆盖校验、捕获和独立审查全部保留。新工具政策随新任务冻结，旧任务不回填，以避免工具可用性和提示变化破坏历史任务绑定；这也是后续调整该作者接口时需要保留兼容解释的边界。
